# Privacidade

A Vitrine de Carreira v1.1 é um MVP executado integralmente no navegador.

- As informações preenchidas são utilizadas pela própria aplicação para gerar análises e recomendações.
- O progresso é armazenado no dispositivo do usuário por meio do `localStorage`.
- Não existe criação de conta nesta versão.
- Não existe backend ou banco de dados da aplicação armazenando as respostas.
- Os dados preenchidos não são enviados para uma API própria.

O usuário pode apagar o progresso utilizando a opção **Recomeçar diagnóstico** ou removendo os dados do site nas configurações do navegador.

Evite inserir informações confidenciais, senhas, documentos ou outros dados pessoais sensíveis.
