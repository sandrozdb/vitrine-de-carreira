# Roadmap — Vitrine de Carreira

## Agora

- publicar e validar o MVP v1.1;
- testar a jornada completa com usuários reais;
- registrar problemas de compreensão e navegação;
- melhorar heurísticas sem inventar precisão.

## Próximas versões

- aprimorar experiência, acessibilidade e responsividade;
- evoluir regras de análise e comparação com vagas;
- adicionar evidências visuais e testes automatizados;
- acompanhar feedback e prioridades do produto.

## v2

- backend próprio;
- integração segura com uma LLM;
- análises semânticas e recomendações contextuais;
- proteção de credenciais e controles de uso.

```text
Frontend
    ↓
Backend/API
    ↓
LLM
    ↓
Banco de dados
```

Nenhuma chave de API deverá ser exposta no frontend.

## Futuro

- importação do perfil em PDF;
- conta e histórico do usuário;
- dashboard de evolução;
- análise de várias vagas;
- acompanhamento contínuo do posicionamento profissional.

O roadmap não estabelece datas e poderá mudar após a validação do MVP.
