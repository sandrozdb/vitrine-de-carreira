# Como contribuir

Este é inicialmente um projeto pessoal, mas sugestões e melhorias são bem-vindas.

1. Faça um fork do repositório.
2. Crie uma branch para a alteração.
3. Implemente e teste a mudança.
4. Confirme que nenhuma funcionalidade existente foi removida.
5. Abra um Pull Request explicando problema, solução e validação.

Nunca publique senhas, tokens, chaves de API ou dados pessoais reais.
